PERSONAL WORKSPACE INTEGRATION

gws cli

이메일과 학습자료를 개인 지식저장소로 정리하는
Baniota의 개인용 Google Workspace 연동입니다.

이 사이트는 운영 목적과 개인정보 처리 내용을 알리는 공개 안내 페이지입니다. 이메일을 열람하거나 파일을 업로드하는 웹 서비스가 아니며, 이 페이지에서 Google 로그인을 요청하거나 비밀번호·인증 토큰을 수집하지 않습니다.

무엇을 위한 연동인가요?

Gmail 정리
사용자가 지정한 메일을 조회하고 첨부파일을 다운로드합니다. 승인한 규칙에 따라 학습·광고·기타로 분류하고 라벨을 지정하거나 보관합니다.
학습자료 관리
학습에 필요한 내용과 출처를 요약해 사용자의 비공개 Obsidian 지식저장소에 정리합니다.
Google Drive 연동
사용자가 선택한 지식저장소 자료와 강의 산출물을 지정된 Google Drive 폴더에 업로드·다운로드하거나 동기화합니다.
선택적 Workspace 작업
사용자가 해당 기능을 요청하고 권한을 허용한 경우에만 Calendar, Docs, Sheets 및 연락처 API를 활용합니다.

계정 연결과 실행은 별개입니다

실제 연동은 운영자가 관리하는 비공개 실행 환경에서 Hermes Agent와 Google Workspace CLI(gws)를 통해 수행합니다. Google 계정의 OAuth 동의로 허용된 범위 안에서만 작동하며, 권한 동의만으로 자동 분류·파일 동기화·메일 발송이 시작되지는 않습니다. 자동 작업의 대상과 규칙은 별도로 정합니다.

초기 적용 시 메일 분류와 파일 동기화는 검토·검증 단계를 거칩니다. 발송, 삭제, 외부 공유 등은 사용자가 승인한 작업 범위에서만 수행합니다.

데이터를 공개하는 사이트가 아닙니다

메일 본문, 첨부파일, 지식저장소, 강의자료와 인증정보는 이 공개 사이트 또는 공개 소스 저장소에 게시하지 않습니다. AI를 이용하는 작업에서는 사용자가 선택한 모델 제공자에게 필요한 내용이 전달될 수 있으므로, 처리 전에 전송 범위와 제공자의 데이터 정책을 확인해야 합니다.
